# سِتر (Sitr) — مختبر تشفير الصور

مختبر تفاعلي عربي (RTL) لتشفير الصور وفك تشفيرها داخل المتصفح باستخدام **AES-128/256** عبر أنماط **ECB / CBC / CTR**. كل عملية معالجة تجري محلياً على جهاز المستخدم؛ لا تُرفع الصور أو المفاتيح إلى أي خادم.

## التشغيل

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # إنتاج dist/
npm run preview   # معاينة بناء الإنتاج
npm run test:crypto
```

## المزايا

- **تشفير بايتات البكسل الخام** (RGB) داخل Web Worker دون تجميد الواجهة، مع شريط تقدّم حقيقي.
- **ثلاثة أنماط**: ECB (لإظهار تسرّب الأنماط البنيوية)، CBC مع IV عشوائي، CTR بتدفق عدّاد متزايد.
- **إدارة مفاتيح**: مفتاح Hex بطول 64 خانة (256 بت) أو 32 خانة (128 بت)، توليد CSPRNG، اشتقاق PBKDF2-SHA256 من جملة سرية، نسخ إلى الحافظة.
- **نماذج مدمجة**: Tux، Alice (John Tenniel)، ونقش هندسي لاختبار الأنماط.
- **تصدير/استيراد حزمة `.sitr`**: تحتوي التشفير وبيانات الوصف العامة (النمط، الطول، IV، الأبعاد) لفك التشفير لاحقاً.
- **تحقق من السلامة**: رأس بيانات مشفّر داخل الحمولة يرفض المفتاح الخاطئ أو البيانات التالفة (لجميع الأنماط).
- **قراءة أكاديمية حيّة**: إنتروبيا شانون (bits/byte)، عدد الكتل، زمن المعالجة، وشرح للنمط الحالي.

## البنية

```
src/
  App.jsx                  حالة التطبيق وسير العمل
  components/              الواجهة (RTL) ولوحة التحكم والكانفس
  hooks/useAesWorker.js    جسر Web Worker
  lib/
    aesEngine.js           AES خالص (FIPS-197) + ECB/CBC/CTR + رأس التحقق
    imagePipeline.js       ملف → ImageData → RGB والعكس + الإنتروبيا
    cipherFile.js          تنسيق حزمة .sitr
    keyManager.js          CSPRNG + PBKDF2-SHA256
  workers/aes.worker.js    معالجة دون حجب الواجهة
scripts/
  verifyAes.mjs            اختبارات FIPS-197 وNIST SP 800-38A
  verifyUi.mjs             اختبار End-to-End (Playwright/Chrome محلي)
  verifyEdge.mjs           حزم تالفة، أبعاد مزيّفة، صورة 1×1، وعدم وجود طلبات خارجية
```

## ملاحظات أمنية وأكاديمية

- ECB **غير آمن** للبيانات الحقيقية؛ يُعرض هنا لتوضيح تسرّب الأنماط البصرية (تأثير Tux).
- يُشفَّر RGB مع حفظ قناة الشفافية لجعل الناتج قابلاً للعرض بصرياً.
- حد أقصى 1200px لأطول ضلع لأسباب أداء، وتُبلَّغ الواجهة عند إعادة التحجيم.
- حزمة `.sitr` تحمل بيانات وصفية غير سرية؛ المفتاح لا يُضمَّن فيها إطلاقاً، ويُتحقق من اتساق الأبعاد مع طول الحمولة قبل أي تخصيص للذاكرة.
- الاشتقاق من الجملة يستخدم ملحاً ثابتاً (`Sitr-ImageCipher-v1`) و150,000 دورة، بهدف قابلية إعادة الاشتقاق في هذا المختبر التعليمي.
- المفاتيح لا تُحفظ بين الجلسات: بعد إعادة تحميل الصفحة يلزم إدخال المفتاح الأصلي لفك تشفير حزمة `.sitr`.
- أثناء المعالجة تُقفل عناصر التحكم لمنع تغيير الصورة أو النمط أو المفتاح في منتصف العملية.
